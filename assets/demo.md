# Calculator Vibe Demo

This file will contain a GIF demonstrating the calculator app functionality.

To create the demo:
1. Run the app on an Android device or emulator
2. Perform the following operations:
   - Basic arithmetic: 2+2, 10-3, 6×7, 15÷3
   - Precedence: 1+2*3, (1+2)*3
   - Decimals: 0.1+0.2
   - Percent: 100%
   - Toggle sign: ±5
   - Theme toggle: Switch between light and dark mode
   - History: View calculation history
   - Copy result: Tap copy icon
3. Record the screen (max 10 seconds)
4. Convert to GIF using a tool like ezgif.com or CloudConvert
5. Replace this file with the actual demo.gif

Recommended recording settings:
- Resolution: 1080x1920 (portrait)
- Frame rate: 30 fps
- Duration: 8-10 seconds
- File size: < 5MB
